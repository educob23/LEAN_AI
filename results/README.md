## File format

`results.jsonl` has one line per theorem:

```json
{"theorem": "mathd_algebra_182", "solved": true, "check": 1, "proof": "theorem ...", "elapsed_s": 3.1, "ts": 1791073394.2}
```

`check` is `1` (verified), `"timed_out"` (budget used up without a verified proof),
`"repl_gave_up"` / `"unexpected_error"` (harness problem; the theorem is marked failed).

`attempts.jsonl[.gz]` has one line per model attempt: `theorem`, `attempt` (0-based),
`raw_text` (full model output), `proof` (extracted Lean code), `answer` (raw Lean REPL
response), `check` (`1` verified · `-1` rejected · `0` contains `sorry` · `null` no code
block), `elapsed_s`, `ts`.

## Archiving a run

`run_batch.py` writes its live logs at the repository root (git-ignored). When a run is
finished:

```bash
RUN=results/<date>_<model>_<split>_<budget>
mkdir -p $RUN
cp valid_results_300s.jsonl $RUN/results.jsonl
gzip -9c attempts_300s.jsonl > $RUN/attempts.jsonl.gz
python scripts/summarize_results.py $RUN
```
